# Aeroven Global IT Solutions — Website

Next.js (App Router) + React marketing site built from the Aeroven design mockups.

## Stack

- Next.js 16 / React 19
- TypeScript
- Tailwind CSS 4
- Framer Motion
- Plus Jakarta Sans

## Pages

| Route | Page |
| --- | --- |
| `/` | Home |
| `/capabilities` | Capabilities |
| `/process` | Process |
| `/engagement` | Engagement |
| `/success` | Success / case studies |
| `/careers` | Careers |
| `/consultation` | Book a consultation |

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

Design source mockups live in the parent `Aeroven Global IT` folder (`*.dc.html`). Brand assets are in `public/brand/`.
